The class's whip count on the world map: a token on each country in the room. While predictions come in, the tokens show only how many calls each country has (never which way, so no one is steered). Once voting opens, the countries take the class's call; once it closes, the real vote, with each token ringed green where the class called it right and red where it missed. The projector shows the same map.
